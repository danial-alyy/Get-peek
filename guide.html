How to Use GIT-PEEK PRO

Inspect GitHub profiles on any webpage seamlessly with contextual hover previews and automated recent history tracking.

01

Activate the Extension

Ensure the Extension Active toggle inside the GIT-PEEK PRO toolbar popup is turned ON (green indicator).

02

Open GitHub or Any Webpage

Browse GitHub normally or visit any blog, documentation site, or portfolio that contains direct GitHub profile links.

03

Hover Over a Profile Link

Pause your mouse cursor over any developer profile link (e.g. github.com/torvalds) for approximately 500ms.

04

Check the Preview Card

A floating card with the developer’s avatar, real name, bio, public repositories, and follower counts appears near your cursor.

05

View Recent Lookups

Click the toolbar icon to view your Recent Lookups history. Click any profile card to jump directly to their GitHub page.

06

Track Session Overview

Monitor your live session metrics: Profiles Viewed (unique), API Requests, and Cached Profiles, with one-click reset.

💡
Privacy & Performance Note: Recent profiles are saved locally inside your browser storage (chrome.storage.local) for instant access. No tracking, zero bloat, and zero duplicate API requests.
